Results

What changed across unseen scenes?

Five neural models were tested on the same set of 96 scenes, with the planner unchanged. The first three were frozen before this test. The two new-approach rows were trained once and scored once, with no tuning on these scenes. This set has been scored and shown before, so treat it as a public benchmark, not a fresh holdout.

Two routes to the same score

Known geometry

Given: where the walls and the bumper are, written into the model.

Learned: how the puck glides, bounces off a wall and bounces off the bumper, with separate pieces and collisions in surface coordinates.

Score: 96 of 96 on the 96 scenes.

New approach: inferred geometry

Given: nothing about the table's numbers.

Found from the training data: the drag, the wall positions and the bumper's centre and radius. The same kind of model is then built on those found numbers.

Score: 96 of 96 with the larger dataset, 94 of 96 with only the original 30,000 transitions.

What both still assume is the form of the table: straight reflecting walls and one round bumper. The new approach removes the hand-written numbers, not that assumption. The new approach is scored by script and is also selectable in the Lab in host view.

How to read this

  • Same planner, different models. The only thing that changed between rows is the network that predicts the next state. So the gains come from better predictions, not from a smarter search.
  • The newest model reaches all 96 targets. It uses the same training observations as the previous improved model but stores collision responses relative to the surface, so a collision at any angle shares one learned response.
  • “New failures vs original” is 0. Nothing the original network hit was lost by the later models.

What this does not show

  • One trained model per row, one training seed. It says nothing about how much results vary between training runs.
  • One deterministic simulator with fixed geometry, friction and one bumper. It does not cover noise, other geometry or a real robot.
  • Several things changed together in the newest model (coordinates, layer structure, seed, optimiser settings), so this table cannot say which one mattered most.
  • Known geometry is a supplied prior. It routes states and transforms coordinates; the collision responses themselves are learned.
